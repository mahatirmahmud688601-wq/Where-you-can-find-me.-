## Core Engineering Principles

1. **Offline-First Sovereign Data**: Local SQLite (Room / SQLCipher) storage ensures 100% operational capability with zero network connectivity.
2. **Sub-16ms Interaction Budget**: MVI and BLoC architectures guarantee smooth 60fps to 120fps display rates without layout thrashing.
3. **Hardware-Backed Encryption**: High-consequence user data secured with AES-256-GCM using hardware-backed Android Keystore keys.
4. **Context-Aware Grounded AI**: Gemini multimodal pipelines run with structured JSON output contracts to ensure deterministic application states.

## Local Development & Setup

### Prerequisites
- Node.js 18+ or Bun
- NPM or PNPM

### Installation & Execution
```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Run type check and lint
npm run lint

# Compile production build
npm run build
```
